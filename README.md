# 1131503_圖書管理程式

這是一個使用 C# Windows Forms 製作的簡易圖書管理程式。  
使用者可以切換不同的圖書顯示方式，並透過雙擊書籍將書籍加入借書清單。

## 功能介紹

- 顯示多本書籍資料
- 支援不同檢視模式：
  - 大圖示
  - 詳細資料
  - 小圖示
  - 清單
  - 大圖示加詳細資料
- 顯示書籍資訊：
  - 書名
  - 作者
  - 類別
- 使用者可雙擊書籍進行借閱
- 借閱前會跳出確認視窗
- 已借閱的書籍不會重複加入借書清單

## 開發環境

- Visual Studio
- C#
- .NET Framework
- Windows Forms

## 畫面說明

程式主要畫面包含：

- 左側：書籍清單
- 右上：檢視方式選單
- 右下：借書清單

使用者可以透過下拉選單改變書籍清單的顯示方式。

## 使用方式

1. 開啟 Visual Studio
2. 載入專案
3. 執行程式
4. 使用「檢視方式」下拉選單切換顯示模式
5. 雙擊想借閱的書籍
6. 在確認視窗中選擇「是」
7. 書籍會加入右側借書清單
